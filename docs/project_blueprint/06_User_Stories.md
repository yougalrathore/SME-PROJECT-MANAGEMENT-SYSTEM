# User Stories

## Admin

### Authentication

**US-001**

As an Admin,

I want to securely log in to the system,

So that I can manage organizational resources safely.

---

**US-002**

As an Admin,

I want to change my password,

So that I can maintain account security.

---

### Projects

**US-003**

As an Admin,

I want to create new projects,

So that I can organize client work efficiently.

---

**US-004**

As an Admin,

I want to edit project information,

So that I can keep project details accurate and up to date.

---

**US-005**

As an Admin,

I want to archive completed projects,

So that I can keep the workspace organized.

---

### Teams

**US-006**

As an Admin,

I want to create project teams,

So that I can organize employees effectively.

---

**US-007**

As an Admin,

I want to assign Project Managers to projects,

So that each project has responsible leadership.

---

**US-008**

As an Admin,

I want to assign Team Members to projects,

So that project work is distributed appropriately.

---

### Budget

**US-009**

As an Admin,

I want to define project budgets,

So that project spending can be controlled.

---

**US-010**

As an Admin,

I want to update project budgets,

So that financial information remains accurate.

---

### Invoice

**US-011**

As an Admin,

I want to generate project invoices,

So that clients can be billed correctly.

---

**US-012**

As an Admin,

I want to review invoice records,

So that I can monitor project billing.

---

### Dashboard

**US-013**

As an Admin,

I want to view an organizational dashboard,

So that I can monitor projects, budgets, and team performance.

---

## Project Manager

### Authentication

**US-014**

As a Project Manager,

I want to securely log in,

So that I can manage my assigned projects.

---

### Project Management

**US-015**

As a Project Manager,

I want to view my assigned projects,

So that I can manage ongoing work.

---

**US-016**

As a Project Manager,

I want to update project progress,

So that stakeholders can track project status.

---

### Task Management

**US-017**

As a Project Manager,

I want to create project tasks,

So that project work is properly planned.

---

**US-018**

As a Project Manager,

I want to assign tasks to Team Members,

So that responsibilities are clearly distributed.

---

**US-019**

As a Project Manager,

I want to define task priorities,

So that important work is completed first.

---

**US-020**

As a Project Manager,

I want to set task deadlines,

So that project schedules remain on track.

---

**US-021**

As a Project Manager,

I want to update task status,

So that project progress is accurately reflected.

---

### Team Allocation

**US-022**

As a Project Manager,

I want to view assigned team members,

So that I can coordinate project activities efficiently.

---

### Budget Management

**US-023**

As a Project Manager,

I want to monitor project budget utilization,

So that project expenses remain within budget.

---

### Invoice Management

**US-024**

As a Project Manager,

I want to review project invoices,

So that I can verify billing information before completion.

---

### Dashboard

**US-025**

As a Project Manager,

I want to view a project dashboard,

So that I can monitor tasks, deadlines, and project progress.

---

## Team Member

### Authentication

**US-026**

As a Team Member,

I want to securely log in,

So that I can access my assigned work.

---

### Task Management

**US-027**

As a Team Member,

I want to view my assigned tasks,

So that I know what work I need to complete.

---

**US-028**

As a Team Member,

I want to update the status of my tasks,

So that the Project Manager can track progress.

---

**US-029**

As a Team Member,

I want to view task deadlines,

So that I can complete work on time.

---

### Project Management

**US-030**

As a Team Member,

I want to view project information,

So that I understand project objectives and requirements.

---

### Dashboard

**US-031**

As a Team Member,

I want to view my personal dashboard,

So that I can monitor my assigned tasks and deadlines.

---

### Team Allocation

**US-032**

As a Team Member,

I want to see my assigned project team,

So that I know who I am collaborating with.
