# Project Scope

## Purpose

The SME Project Management System is designed to provide a centralized web-based platform for planning, managing, and monitoring software development projects within Small and Medium Enterprises (SMEs). The system aims to improve project organization, team coordination, task tracking, budget monitoring, invoice management, and decision-making through role-based access control and analytical dashboards.

The project is developed as a Final Year Project and focuses on implementing essential project management functionalities using modern web technologies while maintaining a scalable and maintainable software architecture.

---

## In Scope

The system includes the following functional modules:

### Authentication
- Secure user registration and login.
- Password encryption and secure authentication.
- Session management and user logout.
- Role-based access authentication.

### Role-Based Access Control (RBAC)
- Three supported user roles:
  - Admin
  - Project Manager
  - Team Member
- Role-specific permissions and system access.
- Restricted access to authorized resources and operations.

### Project Management
- Create, update, view, and delete projects.
- Store project details including:
  - Project name
  - Description
  - Timeline
  - Status
  - Budget
- Monitor project progress throughout its lifecycle.

### Task Management
- Create and assign tasks to team members.
- Update task status.
- Set task priorities and deadlines.
- Track task completion progress.

### Team Allocation
- Assign team members to projects.
- Allocate project responsibilities.
- Manage project teams based on assigned roles.

### Budget Management
- Define project budgets.
- Record project expenses.
- Monitor budget utilization.
- Compare allocated and utilized budgets.

### Invoice Management
- Create project invoices.
- Manage invoice records.
- Track invoice status.
- Maintain invoice history for completed projects.

### Dashboard & Analytics
- Project summary dashboard.
- Task completion statistics.
- Budget overview.
- Invoice overview.
- Project progress visualization.
- Basic reporting using charts and summary metrics.

### Target Users
The system is intended for:
- Small and Medium Enterprises (SMEs)
- Software Houses
- Freelancers
- Digital Agencies

---

## Out of Scope

The following features are intentionally excluded from Version 1 of the system:

- Mobile application development.
- Artificial Intelligence (AI) features.
- Machine Learning capabilities.
- Real-time chat or messaging.
- Audio or video calling functionality.
- Online payment gateway integration.
- Multi-language support.
- Multi-currency support.
- Desktop application.
- Third-party integrations with external services or platforms.
- Advanced workflow automation.
- Customer Relationship Management (CRM) functionality.
- Human Resource Management (HRM) modules.
- Inventory or asset management.
- Email marketing or campaign management.
- Business Intelligence beyond basic dashboard analytics.
