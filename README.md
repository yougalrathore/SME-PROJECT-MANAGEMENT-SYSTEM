# SME Project Management System

Centralized web-based project management platform designed for Small and Medium Enterprises (SMEs) to handle tasks, team allocation, budget tracking, invoicing, and analytics.

* **Institution:** University of Sindh, Jamshoro (Department of Software Engineering)

## 🛠️ Tech Stack
* **Backend:** Python, Django, Django REST Framework (DRF)
* **Frontend:** React, Vite, Tailwind CSS
* **Database:** PostgreSQL / MySQL
* **Tools:** Figma, Git/GitHub, GitHub Codespaces

## 📂 Repository Structure
* `/backend` — Django REST API project workspace
* `/frontend` — React (Vite) single-page application workspace
* `/docs/project_bible` — Core project specification and architectural documentation
* `/design` — UI/UX wireframes, ER diagrams, and system architecture models
* `/.github` — CI/CD workflows and repository automation
